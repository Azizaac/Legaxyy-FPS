Changelog

Rilis versi 1.2.1 terbaru

[Versi 1.2.1] - PERBAIKAN KRITIS: Dashboard blank + "Connecting..." terus saat memakai tarif 1.300/3.500/6.600 VA (bug koma desimal yang merusak script dashboard). Pengguna v1.2.0 wajib update. - Tarif kini dikirim sebagai JSON agar kebal terhadap format angka Windows Indonesia. [Versi 1.2.0] - PERBAIKAN: Tarif PLN di OSD in-game sekarang selalu sync dengan dashboard (tidak lagi nyangkut di 900 VA). - Dashboard jadi acuan tunggal: ganti golongan daya lalu Simpan, OSD ikut berubah dalam <1 detik. - Sinkronisasi otomatis setiap dashboard dibuka, termasuk memulihkan setting yang sempat desync. - Tambah endpoint /api/pln (GET) untuk membaca konfigurasi tarif backend. - Dashboard kini selalu disajikan dari aplikasi (tidak tertimpa file index.html basi). [Versi 1.1.0] - FITUR BARU: Auto Update langsung di dalam aplikasi (tanpa download installer manual lagi). - Peningkatan kestabilan pembacaan FPS via RTSS shared memory bridge. - Optimalisasi konsumsi memori background service dan WebView2 engine. - Penyesuaian skema kalkulasi tarif listrik PLN 900VA & 1300VA. - Perbaikan bug saat minimize overlay window.
