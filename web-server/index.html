Yang bisa dia lakukan.

  1. 01

    Tracker listrik akumulatif

    Mengukur daya rig tiap detik lalu mengakumulasinya jadi total kWh harian dan bulanan. Biaya listrik di OSD dan dashboard dihitung dari kWh nyata yang sama, bukan estimasi statis.

    kWh · Rp
  2. 02

    OSD in-game via RTSS

    FPS, frametime, 1% & 0.1% low, suhu, dan wattase tampil di atas game layar penuh melalui shared memory RivaTuner — tanpa input lag, dengan beberapa pilihan gaya tampilan.

    4 gaya
  3. 03

    Pembacaan sensor tingkat kernel

    Didukung LibreHardwareMonitor untuk membaca suhu inti, hotspot, clock, fan RPM, dan sensor daya PSU secara aman dan akurat.

    LHM
  4. 04

    Pengaturan terpusat di dashboard

    Mode Gamer/Streamer, OSD RTSS, startup, dan tarif listrik diatur dari satu panel — tanpa mengutak-atik menu tray Windows.

    Dashboard
  5. 05

    Auto-update terverifikasi

    Pembaruan muncul langsung di dalam aplikasi. Installer diverifikasi dengan checksum SHA-256 sebelum dijalankan, dan server WebSocket hanya mendengarkan di localhost.

    SHA-256
  6. 06

    Estimasi daya universal (PC & laptop)

    Mendeteksi otomatis tipe perangkat — desktop atau laptop — lalu menghitung daya total dari komponen: CPU, GPU, RAM, storage (NVMe/SSD/HDD), platform, dan display. Database TDP CPU/GPU bisa kamu edit sendiri.

    PC · Laptop
  7. 07

    Rincian daya per-komponen

    Lihat pecahan watt tiap bagian rig di kartu Power dashboard — bukan cuma angka total, tapi tahu ke mana dayanya pergi.

    Breakdown
  8. 08

    Angka jujur, bukan asal

    Nilai dari sensor hardware tampil apa adanya; nilai yang diestimasi ditandai ~. Kalau board-mu punya sensor PSU asli, total watt langsung terukur tanpa tanda.

    Transparan

/ Pertanyaan

Hal yang sering ditanya.

Apa saja yang dibutuhkan untuk menjalankannya?

Windows 10/11 64-bit. WebView2 dan RivaTuner Statistics Server sudah disiapkan otomatis oleh installer, jadi kamu tidak perlu memasangnya manual.

Apakah wajib memakai RTSS?

Tidak wajib. Aplikasi tetap berjalan dan menampilkan sensor tanpa RTSS, hanya saja data FPS/frametime tidak akan muncul sampai RTSS aktif menangkap game.

Apakah data saya dikirim ke internet?

Tidak. Semua pembacaan sensor diproses di komputer kamu. WebSocket hanya mendengarkan di localhost, dan server pembaruan dipakai satu-satunya untuk mengecek versi baru.

Apakah aplikasinya gratis?

Ya. LegaxyyFPS gratis dan open source. Kode sumbernya tersedia di GitHub.

Apakah angka dayanya akurat?

FPS, suhu, clock, dan beban dibaca langsung dari sensor. Untuk daya total sistem, sebagian PC/laptop tidak punya sensor PSU, jadi angkanya diestimasi dari sensor CPU/GPU ditambah database komponen — nilai estimasi selalu ditandai ~. Kalau board-mu punya sensor PSU asli, total watt terukur penuh tanpa tanda.
