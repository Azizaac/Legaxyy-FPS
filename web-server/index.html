Fitur Utama LegaxyyFPS

Dirancang untuk gamer dan power-user yang menginginkan akurasi tanpa lag.

🎯

Realtime FPS & Frametime

Terintegrasi langsung dengan RTSS (RivaTuner Statistics Server) untuk deteksi framerate akurat dan mulus di semua game DirectX, Vulkan, dan OpenGL.

⚡

Sensor Hardware Lengkap

Membaca suhu CPU, GPU, penggunaan RAM, clock speed, dan wattase realtime menggunakan LibreHardwareMonitor tingkat kernel.

💡

Kalkulator Biaya Listrik PLN

Otomatis menghitung konsumsi watt dan mengonversinya ke estimasi rupiah per jam berdasarkan tarif listrik rumah tangga Indonesia.

🔄

In-App Auto Update

Tidak perlu unduh dan pasang manual lagi! Aplikasi memiliki tombol periksa pembaruan dan mengunduh rilis terbaru langsung dari server.

🖥️

Native WebView2 Overlay

Tampilan antarmuka futuristik, bisa diposisikan di layar utama maupun monitor kedua, dan bisa di-resize sesuai kebutuhan.

🚀

Ringan & Minim Resource

Berjalan di background system tray tanpa membebani CPU, sehingga tidak memicu FPS drop saat bermain game kompetitif.
