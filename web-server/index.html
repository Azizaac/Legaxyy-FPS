Kelebihan LegaxyyFPS

Dibangun Khusus Untuk Gamer & Enthusiast

Akurasi tinggi, tanpa overhead resource, dan memberikan data yang benar-benar kamu perlukan saat gaming.

⚡

Tracker Listrik Akumulatif (kWh Real-Time)

Bukan lagi sekadar estimasi statis! LegaxyyFPS mengukur konsumsi watt rig kamu setiap detik lalu mengkalkulasikannya menjadi total kWh riil. Data disimpan aman ke penyimpanan lokal setiap 60 detik agar kamu tahu persis berapa rupiah biaya listrik yang dihabiskan untuk sesi gaming hari ini maupun bulan ini.

FITUR TERBARU v1.3.0
🎮

RTSS In-Game OSD Injection

Tampilkan FPS, Frametime 1% & 0.1% Low, suhu, dan wattase langsung di atas game layar penuh via shared-memory RivaTuner Statistics Server tanpa input lag.

4 GAYA TAMPILAN OSD
🔬

Sensor Hardware Tingkat Kernel

Didukung oleh LibreHardwareMonitor untuk membaca suhu inti CPU/GPU, Hotspot, Clock MHz, Fan RPM, tegangan, dan sensor PSU secara aman tanpa risiko crash.

⚙️

Pengaturan Terpusat di Dashboard

Tidak perlu lagi mengutak-atik tray menu Windows yang ribet. Buka modal pengaturan langsung dari tombol ⚙ di dashboard untuk ganti mode, OSD, startup, dan tarif PLN.

BARU DI v1.3.0
🔄

In-App Auto Update

Pemberitahuan pembaruan versi langsung muncul di dalam aplikasi. Kamu cukup klik satu tombol untuk mengunduh dan memasang versi terbaru secara instan.
